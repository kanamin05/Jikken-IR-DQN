# 物体ごとの半径への更新

既存フォルダの environment.py と visualize_paths.py をバックアップし、
この2ファイルのみ置き換えてください。train_dqn.py の定期保存設定は維持します。
地図・モデル・仮想環境は既存のものを使用します。

半径はモデル原点を基準にした計測値を切り上げ、foam_brick=0.08 m、
lego_duplo=0.19 m。margin=0.03 mは2次元比較用の仮値です。
Legoは検出ラベルで7種類を区別できないので最大モデルの値を使用します。
Foamは円形近似でも小さくなります。矩形と向きの推定は未実装です。

衝突判定、配置の重なり判定、入力マップ、可視化を個別の半径にそろえました。
合成環境ではラベルを等確率で選び、そのラベルは理想的に認識される仮定です。
既知の合成物体IDは記憶用で、DQN入力には渡しません。
ROSに接続するときは認識ラベルで同じ寸法表を参照します。
モデル原点と検出位置のずれはまだ測定していません。

入力の次元数は2702のままですが、障害物分布と入力の意味が変わります。
旧モデルを保存し、新規学習してください。
配置範囲 x=[1.00,2.85], y=[2.85,3.80] は仮のままです。

## 実行
```bash
.venv/bin/python environment.py
nohup bash run_training.sh > train_individual_sizes.log 2>&1 < /dev/null &
tail -f train_individual_sizes.log
```
run_training.sh は既存の --obstacles 1 --steps 10000 を使用します。
チェックポイント保存先が旧runと同じ場合は、事前に別名へ変えてください。
完了後:
```bash
.venv/bin/python -u visualize_paths.py
```

作成側では環境のリセット、個別半径の衝突判定・入力反映、到達・壁判定を確認。
DQN学習と描画の実行は作成側では未検証です。
